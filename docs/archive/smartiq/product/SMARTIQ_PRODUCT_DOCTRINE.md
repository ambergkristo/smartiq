# SmartIQ Product Doctrine

## 1) Purpose

This document defines the strategic direction of SmartIQ.

Its job is to keep product decisions coherent as the repository grows. New features, product initiatives, and documentation changes must align with this doctrine. If a proposed addition does not strengthen the doctrine, it should not enter active development.

## 2) Product Stage

SmartIQ is currently a:

**Playable product with SaaS ambition.**

This means the core game loop exists and can be run, but the product is not yet mature enough to be treated as a fully proven recurring SaaS business.

## 4) Strategic Principles

- Gameplay experience > admin features
- Multiplayer reliability before monetization
- Content supply before scale marketing
- Host retention before host acquisition
- No feature development without milestone alignment

## 5) Control Rule

Every new feature must belong to a defined milestone.

If a feature does not clearly map to an approved milestone, do not implement it.
