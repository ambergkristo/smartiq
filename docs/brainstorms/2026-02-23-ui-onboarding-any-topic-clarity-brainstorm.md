# UI Onboarding: Any Topic Clarity

## What We're Building
A small, UI-only clarity pass on the setup screen so the default Topic choice (“Any Topic”) feels intentional and easy to understand. The goal is faster onboarding for casual players by removing uncertainty at the first decision point without changing the game flow or data behavior.

## Why This Approach
We chose the smallest change that addresses the stated friction: the default topic is unclear. Instead of adding new flows or defaults, we will keep “Any Topic” as the default and make its purpose obvious through concise copy and visual emphasis. This aligns with YAGNI and avoids introducing new UX paths that require additional testing or logic changes.

## Key Decisions
- Keep “Any Topic” as the default: User preference and low risk.
- Focus on clarity, not behavior change: The intent is to reduce hesitation, not alter selection logic.
- Optimize for casual players: Prioritize quick comprehension over advanced customization.
