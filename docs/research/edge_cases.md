# PPTX FIXER Edge Cases

## Purpose

Track observed formatting drift patterns found in the deck corpus so the team can prioritize realistic audit and auto-fix targets later.

## How To Use This Document

This document captures observed formatting drift patterns from the deck corpus. Add examples only when they are seen in real decks or sanitized corpus samples.
