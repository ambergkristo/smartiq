# Project Pivot Note

SmartIQ has evolved into CherryPick.

CherryPick is a hybrid quiz game platform with a new product direction built around:

- single-player quiz play
- couch multiplayer
- join-code live sessions
- XP progression
- cherry-based reward mechanics

The product direction is no longer centered on the previous SmartIQ recurring-host SaaS framing.

CherryPick keeps the quiz foundation, but changes the gameplay and product strategy toward a broader game platform with new progression, reward, and mode design.

Previous SmartIQ planning documents are archived to avoid product drift and documentation conflicts during the transition.
